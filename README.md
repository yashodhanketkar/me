Yashodhan Ketkar | Personal website
===================================

This is a source code for my personal website.

This project was built using React, Tailwind css, Firebase, and Redux Toolkit.

Key Features
------------

-	Responsive Design: Optimized for all screen sizes using Tailwind CSS.
-	State Management: Efficient data handling with Redux Toolkit.
-	Hosting: Reliable and secure deployment via Firebase.
